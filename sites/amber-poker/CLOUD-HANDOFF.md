# Codex Cloud 移行手順

このフォルダーは最新のゲーム、テスト、単体版、仕様書を含む。元の.gitや認証情報は含めない。既存Siteの識別設定は同じゲームの公開再開用に保持している。

1. この内容を指定したGitHubリポジトリにアップロードし、保存されたことを確認する。
2. ChatGPT／Codexの「Work in > Cloud」で環境を選択、または作成する。
3. 対象GitHubリポジトリを選ぶ。Node.js 20以上を使用する。外部依存のインストールは不要。
4. セットアップ検証は `cd amber-poker` → `npm run build` の後に `npm test`。環境を保存・Publishする。
5. クラウド環境からタスクを開始し、以下の依頼文を送る。

## 最初のクラウドタスク用依頼文

このリポジトリのamber-poker/にあるAMBER POKERをローカルPCからCodex Cloudへ移行しています。作り直さず最新ソースを引き継いでください。AGENTS.md、README.md、AMBER-POKER-SPEC.mdを読み、npm run build→npm testを実行して修正が必要なら修正してください。37件のテストが既存の基準です。ブラウザーが使える場合は画面と操作も確認し、未確認項目を区別してください。D/Spaceの状態別主操作、W/SのBET・HIGH/LOW、AのCOLLECT、テンキー・タッチ操作を維持してください。ゲームと仕様書の変更をコミットしてリモートに保存してください。今回はSites公開は行わず、移行・検証結果と再開方法を報告してください。

## 保管

移行完了はGitHubへのソース保存とクラウドタスクでの検証を確認した時点。ZIPをローカルに作成しただけでは移行完了ではない。クラウド作業中の変更も適宜コミットしてリモートへ保存する。
