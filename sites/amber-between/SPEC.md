# AMBER BETWEEN v1

仕様の基準: [Notion「Amber Betweenの作成」](https://app.notion.com/p/3f6ebdc34b6e80a7ad7ecca9e8aa6435)（2026-10-11更新、2026-10-12参照）。1990年代のSIGMA BETWEEN CARDSを参考にする独立ゲーム。

## Notionに記載されたルール

BET → DEALで2枚表示、SPREADとPOSSIBLE HAND表示 → DRAWで裏向きの5枚 → 1枚を選び全5枚公開 → 選択した1枚と基準2枚で判定。当たりならダブルの権利。ダブルは裏向き2枚のLEFT/RIGHTから大きい方を選択し、勝利でWIN倍増、同値はWIN維持で自動配り直し。選択前のCOLLECT可。敗北でWINを失う。

| 役 | BET倍率 |
| --- | ---: |
| J-Q-K OF SPADE | 500 |
| J-Q-K WITH FLUSH | 100 |
| THREE A’s OR 7’s | 50 |
| THREE J’s, Q’s, K’s | 20 |
| THREE OF A KIND | 10 |
| 1 CARD SPREAD | 5 |
| 2 CARDS SPREAD | 4 |
| 3 CARDS SPREAD | 3 |
| 4–11 CARDS SPREAD | 2 |
| PAIR W/O SPREAD | 1 |

## 未記載部分の実装上の解釈

実機の公式マニュアルは確認できていない。公開調査で確認した[トップラインの実機紹介](https://topline.royalflush.jp/sigma-between-cards/)も詳細ルール不明と記載している。以下は実機の完全再現を主張するものではなく、本アプリの明示的な規定。

- ジョーカーなし52枚。2 < 3 < … < 10 < J < Q < K < A（14）。同一ラウンドは重複なし。新規DEALとダブルの各試行ごとにシャッフル。
- BETは1〜10枚。MINで予約解除（0）、MAXで最大10枚。BET 0ではDEAL不可。総残高0枚で無料補充。
- SPREADは基準2枚の間の数字の個数。選択カードが厳密に間にある時にSPREAD配当。SPREADが1以上のとき、端と同値はNO WIN。
- 特別役は基準2枚と選択1枚を順不同で判定し、配当表の最上位1役のみ採用。同一スートのJ-Q-Kは選択カードが端の外でも成立。
- PAIR W/O SPREADはSPREAD 0で選択カードがどちらかの端とペアになる場合に×1（2026-10-12、日本時間のユーザー指定）。6と7なら6または7で成立。最初の2枚が同じ数字なら、選択カードも同じ数字のときはスリーカードを優先し、別の数字ならNO WIN。
- 倍率はBET分を含む総払戻。BET予約時にCREDITから移動し、DEALで再控除しない。終了後は前回BETを残高の範囲で次回分として予約。
- 左右のダブルは数字のみを比較。スートは強さに影響しない。同値時は直前の結果を記録して新しい2枚を裏向きで配る。
- WINはCOLLECTまで未回収。安全整数を超えるダブルは無効。保存はブラウザー単位、別タブの変更を操作前に検出して停止する。
